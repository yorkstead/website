# Industry consultation playbooks

## User value

The Yorkstead owner can start a discovery conversation from the client’s operating environment, capture the evidence and baseline measures that matter in that industry, and leave with a clear recommendation across the current Yorkstead offer ladder: Workflow Rescue, Workflow Sprint, Department System, or Company Operations System.

## Scope

- Replace service-first consultation templates with an industry-first library.
- Cover manufacturing and fabrication, sign/CNC/custom production, warehousing and freight, restaurants and hospitality, contractors and field service, retail/ecommerce/marketplaces, and professional/back-office services.
- Preserve public-service attribution for lead routing and existing consultation records.
- Add industry-specific workflow patterns, evidence requests, baseline measures, caution signals, discovery prompts, and development gates.
- Make copied briefings useful as an Operations Systems Blueprint starting point.
- Document how the playbooks support Yorkstead’s purchased-software and optional-support model.

## Acceptance criteria

- The consultation dashboard presents templates by industry rather than by public service.
- Every template recommends the current Yorkstead engagement ladder and records one bounded first workflow.
- Each industry includes at least five call-plan steps, four evidence requests, four baseline measures, four caution signals, five guided sections, fifteen prompts, and five development-gate checks.
- Existing records without an industry identifier still open against a compatible default template.
- New records retain a stable industry identifier inside the existing response document, requiring no database migration.
- Copied Markdown briefings name the industry, related service, recommended commercial path, captured answers, baseline measures, and development gate.
- Tests, lint, typecheck, migration check, and production build pass.

## Non-goals

- Changing public service pages or prices.
- Automatically producing a binding proposal, estimate, architecture, or ROI claim.
- Adding client-side database access or collecting sensitive operational records in a public form.
- Reclassifying existing consultation records through a database migration.
