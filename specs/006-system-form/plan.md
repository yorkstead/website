# Implementation plan

1. Model deterministic target coordinates and tangents for the six distinct forms in a framework-neutral module.
2. Render the population as an instanced rod mesh plus a point cloud inside one fixed React Three Fiber canvas.
3. Attach reversible, scrubbed GSAP ScrollTriggers to selected homepage sections and the footer, alternating Core with operational drawings through the full page.
4. Add restrained responsive presentation and static fallback styling.
5. Verify geometry invariants, lint, types, tests, migration safety, and production build.
