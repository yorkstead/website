# Yorkstead logo packet

Current approved exports from `yorkstead-logo-master.ai`. The matching master packet lives at `yorkstead-systems/brand/logo`; Obsidian keeps the same 22 assets in `_assets/logo`.

`1x` contains 1001 × 1001 PNGs; `1.5x` contains WebP exports; `2x` contains larger PNGs. `SVG` and `PDF` contain vector exports. Transparent names describe the ink color: use `logo-dark-transparent.png` on light surfaces and `logo-light-transparent.png` on dark surfaces. Opaque names describe the background.

The header, manifest, push notifications, service worker, browser/Apple icons, and embedded social preview use the current exports. Bump the service-worker cache when changing its cached logo. Update manifest dimensions if exports change size.

No existing global visual identity was changed.
