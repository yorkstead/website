The Badge is a small, fully rounded pill for tags and metadata: 11px/500 text with 2px × 8px padding and a 1px border.

**Use**
- `variant="secondary"` for neutral tags such as industry names and tech stacks (`secondary` fill).
- `outline` (the default) as the base for colored badges. Pass the color classes via `className`, as `ProjectStatusBadge` does.

**The consumer provides** the text as `children` and any `className`.

**Don't** use a Badge as a button, and don't carry meaning with color alone.
