SolutionCard sets out one operational problem next to its solution on `/solutions`. It shows the number, a `Wrench` tile, a `primary` status badge, the title, a "The Operational Drag" box tinted `destructive`, a solution box tinted `primary`, a list of composable capabilities, and a demo link when one exists.

**The consumer provides** `solution`: one `SolutionOutcome` from `lib/solutions.ts`.
