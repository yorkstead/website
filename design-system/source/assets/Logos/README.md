These are the approved exports from `yorkstead-logo-master.ai`. The mark is a geometric Y: `mark-ink` arms, a `mark-sky` arm and hub, and a `mark-hub` ring.

- `logo-light.svg` / `logo-light.png`: the mark on its own `mark-tile` light rounded tile. The site header, favicon and app icon use this one.
- `logo-dark.svg` / `logo-dark.png`: the mark on a `mark-ink` dark tile, with light arms.
- `logo-dark-transparent.svg`: dark ink, no tile. Use it on light grounds.
- `logo-light-transparent.svg`: light ink, no tile. Use it on dark grounds.

"Transparent" names describe the ink; opaque names describe the tile. Keep clear space of at least a quarter of the mark's width. Never recolor, rotate or redraw the mark.
